# 使用流程修复与验证

日期：2026-10-01。本轮按用户反馈优先修复点词、跳转与学习进度。它是当前应用的可用性修复，不等于三阶段性能架构的正式发布验收。

## 修复了什么

- 词根和单词可以同名，场景使用 `root:<id>` 与 `word:<id>` 区分；个人进度继续使用原单词 ID。
- 标记后下一词的计时器随关闭、手动切词、重选、切换模式取消；词根聚焦和选词不会互相冲突。
- 保存前合并浏览器最新记录；其他窗口的更新可同步显示。写入失败会提示，界面不会假装保存成功。损坏旧记录保留原文后才允许覆盖。
- 专注学习先隐藏释义，查看答案后评分；忘记的词十分钟后再复习，正确的词从一天开始逐渐延长间隔。旧版只有掌握度的记录也能进入复习。
- 普通学习和复习均排除尚未到时间的词。到期池完成后明确提示，不强行跳回新词。可从词表手动查看任意单词。
- 搜索支持单词、中文和英文释义、词根与拆解；空结果、清空搜索、键盘操作均可用。小屏默认专注学习，选词后自动收起词表。
- 词库加载先检查 HTTP 与数据完整性，失败可重试；不支持 3D 或渲染中断时可继续专注学习。
- 星空按需加载；初始化完成后停止全场力模拟，只更新当前词根的公转及相关线。取消常驻粒子，控制渲染分辨率，光效默认关闭。
- 场景卸载会清理动画、事件、背景与泛光资源；切换模式不会不断叠加画布。
- 补齐 144 条英文释义。新增释义注明为编辑改写；原词 ID、音标、中文释义、拆解和例句保持不变。
- 删除凭前缀猜出的反义关系，纠正人工关系中容易误导的分类。自动生成仅表示词形/词族助记。现有 72 个词根、432 个单词、235 条词间关系。

## 可重复执行的检查

```text
npm ci
npm test
npm run data:check
npm run learning:check
npm run build
npm run backup:check
```

- `npm test`：真实词库、同名节点、关系端点、可重复布局、坏词库拒绝、请求取消/重试，以及词卡关闭/切词/评分/键盘等界面回归。
- `data:check`：生成物与人工源一致、内容完整、错误语义回归与坏数据拒绝；运行不修改学习记录。
- `learning:check`：隔离目录检查真实进度代码，覆盖旧坏记录保护、存储拒绝、多个窗口合并、复习日期和进度导入/导出。
- Mac / Windows 自动检查执行以上流程，不将一次打包通过当成真实设备流畅度证明。

## 实际浏览器检查

在独立浏览器环境使用正式打包页面，测试数据没有写入用户日常浏览器：

- 桌面选择 inspect、标记掌握后关闭，等待旧计时器过期仍保持关闭；刷新后状态和复习日期仍在。
- 自测开始时隐藏答案，查看后内容完整；专注模式没有运行 3D 画布。
- 390 × 844 视口选择 scope 显示范围，词表自动收起；忘记后关闭不会重开。inspect 的关系词点击后打开对应词卡，卡片与操作条没有横向溢出。
- 单独检查 3D 概览、词根公转、同名 scope 的选择、重复导航、线端点对齐和多轮模式切换。

截图和详细本机诊断放在私有备份附件中。英语发音使用系统声音；不同电脑可用的声音不同，不以截图代替实际可听声音检查。

## 性能数字的含义

之前所有页面代码一开始同时下载，约 460.71 kB gzip。本轮将学习入口与星空拆开，入口约 57.6 kB gzip，星空另按需加载约 373.6 kB gzip。专注模式无需下载和绘制星空。数字来自本机构建输出（十进制 kB），后续版本以实际构建为准。

原始版本的本机 rAF 诊断保存在私有附件中；它不是正式 GPU 帧率报告。本轮没有声称真实手机性能、所有设备零故障或三阶段完整通过。三阶段设计与实施计划继续保留，后续应先对照实际代码、补正式证据，不能照旧文档重复引入已修问题。
